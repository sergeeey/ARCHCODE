### ATR framework (`topology_control/`) — Phase 1 завершена, вердикт WEAK

Kill-switch сработал на самом фреймворке: `T2 KILL ∧ D1 KILL → ATR WEAK`, каскад
заблокирован автоматически.

| ветка | вердикт | основание |
|---|---|---|
| **T2** topological annealing | 🔴 **KILL** | оракул устойчив, три локальных правила дали ноль |
| **D1** spectral 3D | 🔴 **KILL** | ΔAUC +0.0004 (v8) → **−0.0007** (v10, 4× данных); знак перевернулся вокруг нуля |
| **H1** redox controller | 🟡 **INCONCLUSIVE** | единственная живая ветка; цепочка R1→R2→R3→R7/R6 замкнута |
| **T1, D2, D3, Phase 3** | ⛔ заблокированы по дизайну | зависят от `SUCCESS` в Phase 1, которого нет |

**Измеренный механизм, объясняющий все три закрытия E–G-направления одной величиной:**
контакт Hi-C на 67% есть функция геномного расстояния — `R² 0.6727 → 0.6734`,
наклон `−0.8212 → −0.8175` (полимерный ~−1), Spearman `−0.790 → −0.792` при переходе
v8→v10. Воспроизводится на 2.5× данных до третьего знака.

**Переносимое предсказание:** любой признак из матрицы контактов Hi-C на разрешении
10 кб даст **ΔAUC < 0.02** над baseline, включающим расстояние. Устояло на v10.

⚠️ **Ослаблено 2026-09-01:** формулировка «канал контакта ПУСТ» неверна. AUC остатка
`0.5063 → 0.5383` при учетверении набора меток — число было свойством **пары**
(Hi-C × разреженные метки v8), не Hi-C. Канал слабый, не пустой. Дешёвая проверка
«AUC остатка ≈ 0.5» больше **не валидный прокси** — проверять надо сам ΔAUC.
Pearl-запись переведена в `weakened`.
