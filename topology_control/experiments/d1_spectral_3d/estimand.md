# Estimand — D1 (переформулированный после `scope_test.md` → REDIRECT)

## L0 — тип вопроса

```
- [ ] Descriptive
- [x] Predictive
- [ ] Causal
```

**Predictive, не causal.** Вопрос: «добавляет ли спектральный признак предсказательную
силу сверх baseline», а не «влияет ли спектр на экспрессию». DAG не строится, каузальные
формулировки запрещены ниже.

Исходная формулировка D1 (`UNIFIED_FRAMEWORK.md:76`) содержала каузальную цепочку
`ΔG → ΔL → Δλ → Δ(экспрессия)`. Здесь она **не проверяется** — проверяется только
предсказание. Это сужение записано осознанно.

## L1 — атрибуты

| Атрибут | Значение |
|---|---|
| **Population** | Пары (вариант, ген). Вариант — лид-eQTL (минимальный `pval_nominal`) какого-либо eGene в GTEx v8 `Cells_EBV-transformed_lymphocytes`. Ген — из GENCODE v26, `protein_coding` или `lincRNA`, TSS в пределах ±500 кб от варианта. Аутосомы chr1–chr22. Требуется ≥2 гена-кандидата в окне |
| **Intervention** | Добавление `spec_resist` (эффективное сопротивление в лапласиане окна) к модели |
| **Comparator** | Baseline-модель: `log10_dist + in_ccre + contact`. **`contact` добавлен redirect'ом** — именно это отличает D1 от двух закрытых проверок |
| **Endpoint** | Значимость пары (вариант, ген) как eQTL в той же ткани |
| **Summary measure** | `ΔAUC = AUC(baseline + spectral) − AUC(baseline)` на отложенных хромосомах |
| **MCID** | `ΔAUC ≥ 0.05` |

**Cell-type matching по построению:** Hi-C — GM12878 (LCL), eQTL — GTEx LCL. Это тот же
тип клеток, а не «подобранный постфактум».

## Intercurrent events (ICE)

| Событие | Доля (замерено на пилоте) | Стратегия |
|---|---|---|
| Бин Hi-C с нулевым покрытием → `spec_resist` вырождается в ~2·10⁹ | **37.2%** пар (`bin_ok = 0`) | **Исключение из первичного анализа.** Такая пара несёт не спектральную информацию, а факт «бин пустой» — то есть прокси для baseline `contact`. Вторичный анализ на всех парах сообщается |
| Вариант без ≥2 генов-кандидатов в окне | малая | Исключён на этапе сборки: задача «выбрать ген» не определена при одном кандидате |

ICE обрабатываются как **события**, не как пропуски. Импутация не применяется.

## Формулировка одним предложением

> Мы оцениваем **прирост AUC** предсказания значимости пары (вариант, ген) для
> **лид-eQTL вариантов GTEx LCL и генов в окне ±500 кб**, сравнивая модель
> **baseline + спектральное сопротивление** против **baseline (расстояние + cCRE +
> сила контакта Hi-C)**, обрабатывая **пары с пустым бином Hi-C** стратегией
> **исключения из первичного анализа**.

Написано до просмотра любого AUC.

## Estimand → Estimator

Estimand — прирост предсказательной способности. Estimator — логистическая регрессия
на ранг-нормированных признаках, без настройки гиперпараметров.

**WHY без настройки:** любой тюнинг на этих же данных внёс бы утечку, которую пришлось
бы отдельно контролировать. Модель без гиперпараметров исключает этот класс проблем
по построению. Градиентный бустинг — пре-регистрированная вторичная проверка на случай
нелинейности, не первичный результат.
