# Claim v2 — TOP2 как топологический отжиг

## Почему v2, а не повторный прогон v1

Механика эксперимента изменилась, поэтому старая пре-регистрация к новой модели не
относится. Три изменения (все — исправления технических ошибок, см. `AMENDMENTS.md`):

1. **Passage теперь меняет топологию.** В v1 это был случайный сдвиг кольца на 0.2,
   дававший `dLk = 0` всегда. Теперь — геометрическое протаскивание дуги, `dLk = ±1`.
2. **Начальная конфигурация действительно зацеплена.** В v1
   `create_linked_rings` возвращала незацепленные кольца (Lk ≈ −0.01 вместо 1) —
   эксперимент стартовал с нулевой топологией.
3. **Точка перекрёстка находится геометрически**, а не берётся как индекс 0.

Прогоны v1 не несут информации о гипотезе и не переносятся.

## EstimandOps L0

**Тип вопроса:** Descriptive.

В системе из N зацепленных колец, где каждое событие strand passage меняет linking
number пары на ±1: **снижает ли правило выбора, использующее ТОЛЬКО локальную геометрию
перекрёстка, суммарную топологическую сложность сильнее, чем случайный выбор?**

Явно **не** причинное утверждение о TOP2 in vivo. Явно **не** заявление о клиническом
применении.

## Zero-Signal Gate

| Поле | Значение |
|---|---|
| Сущность | Система из N замкнутых колец с попарными linking numbers |
| Фальсифицируемый предикат | Локальное правило снижает `C = γ·Σ\|Lk\|` сильнее случайного |
| Измеримый исход | `advantage_score = C_final(biased) / C_final(random)` |

## Три арма + потолок

| Арм | Правило принятия passage | Использует Lk? |
|---|---|---|
| `random` | p = 0.5 (baseline) | нет |
| `angle` | p = exp(−\|θ − π/2\| / 0.5), θ — угол перекрёстка | **нет — только локальная геометрия** |
| `oracle` | принимать, только если passage снижает \|Lk\| пары | **ДА — потолок, НЕ локальное правило** |

**`oracle` — не участник соревнования.** Это системный позитивный контроль: он
показывает, какое упрощение вообще достижимо при данной механике. Без него нельзя
отличить «локальной информации не хватает» от «упрощение невозможно в принципе».

## Замороженный claim (до результатов)

> `advantage_score = C_final(angle) / C_final(random) < 0.7`

Метрика определена как в v1 (`KILL_CRITERIA.md:33`, направление уточнено A-001):
**меньше = лучше.**

| Порог | Значение | Источник |
|---|---|---|
| SUCCESS | `advantage_score < 0.7` | v1, не менялся |
| KILL | `advantage_score > 0.8` | v1, не менялся |
| Серая зона | `0.7 ≤ advantage_score ≤ 0.8` | → INCONCLUSIVE |

## Обязательные гейты (проверяются ДО интерпретации advantage_score)

Введены по итогам `ORACLE_INADEQUACY.md` — каждый закрывает конкретный дефект v1.

| Гейт | Условие | Что ловит |
|---|---|---|
| G1 — есть что упрощать | `C_initial > 0` | дефект 4: старт с нулевой топологией |
| G2 — операция работает | доля \|dLk\| = 1 среди применённых ≥ 0.5 | passage выродился в перемешивание |
| G3 — упрощение достижимо | `C_final(oracle) < C_initial` | различает «правило слабое» и «механика не позволяет» |
| G4 — арм не бездействует | принято passages(angle) ≥ 0.1 × принято(random) | дефект 1: «преимущество» как бездействие |

**Любой непройденный гейт → `BLOCKED-INFRASTRUCTURE`, а не KILL.**
Это не свидетельство против гипотезы (FL Step 2a).

## Обязательные выходные метрики

Публикуются рядом с `advantage_score` — без них артефакт пройдёт незамеченным:

- число принятых passages по каждому арму (метрика, вскрывшая дефект 1)
- доля `|dLk| ≠ 1` (частота отказа операции)
- `C_initial`, `C_final` по каждому арму
- корреляция локального правила с оракулом: доля случаев, где `angle` принял passage,
  который оракул счёл снижающим

## Что этот результат НЕ будет означать

1. **Не** утверждение о поведении TOP2 в живой клетке — это toy model из 50-точечных
   колец без термодинамики и без реальной кинетики фермента.
2. **Не** клиническое применение. Условие возврата №3 автора («прояснена клиническая
   связь») остаётся открытым независимо от исхода.
3. **Не** разблокировка Phase 2 автоматически. `T1 depends on T2 SUCCESS` — но T1
   требует данных суперскручивания, которых нет; успех T2 не создаёт их.
4. **Не** перенос на v1: прогоны апреля 2026 остаются информационно пустыми.

## Запрещённые формулировки

- «TOP2 использует локальные правила» как установленный факт (это toy model)
- «Отжиг подтверждён» без указания, что oracle-арм не является локальным правилом
- Сравнение `angle` с `oracle` как соревнования равных
- Любое клиническое или терапевтическое следствие
