# Claim v3 — кривизна как локальное правило (вариант V1)

## Отношение к v2

v2 убила формулировку «**угловой** bias → отжиг» (медиана 0.919 > 0.8, KILL).
`decision_v2.md` § Relaxation Map предписывает V1: **заменить ровно одно допущение —
локальное наблюдаемое.** Угол → кривизна в реальной точке перекрёстка.

Всё остальное неизменно: пороги, механика passage, оракул, гейты G1–G4, конфигурация.
Это Minimal Relaxation Rule: одно изменение на вариант.

**Почему кривизна вообще кандидат:** в исходном коде v1 она была заявлена
(`strand_passage_curvature_bias`), но никогда не вычислялась — `crossing_point = 0`
попадал под guard `if i < 2: return p_angle`. Гипотеза автора не проверялась ни разу.

## Правило

```
κ  = дискретная кривизна кольца j в точке перекрёстка (угол поворота / длину)
p  = exp(−κ / β),   β = 2.0        # β взято из оригинала topology_utils.py:332
```

Смысл (формулировка автора): TOP2 избегает сильно изогнутых участков — они
энергетически невыгодны.

## ⚠️ Известное ограничение инструмента (замерено ДО прогона)

[VERIFIED, замер 2026-08-30]

| Состояние колец | Кривизна |
|---|---|
| Свежие (идеальные окружности) | **постоянна**: 1.0005, разброс 3.9·10⁻¹⁴ |
| После passage (n=60) | 1.132 … 2.451, медиана 1.900; 100% отличаются от 1/R > 5% |

**На старте прогона правило не различает конфигурации вообще** — κ = 1/R везде, значит
`p = exp(−0.5) = 0.607` для всех перекрёстков, то есть правило вырождается в
фиксированную вероятность. Различающая способность появляется только по мере накопления
деформаций от предыдущих passage.

Следствие: фактически это правило «избегай мест, где passage уже происходил» —
**правило памяти, а не топологии**. Это записано ДО прогона, чтобы результат нельзя
было переинтерпретировать задним числом.

## Статистика — задана ЗАРАНЕЕ (закрывает пробел v2)

`claim_v2.md` не оговорил ни репликацию, ни выбор статистики, из-за чего одиночный
seed 42 дважды выдавал SUCCESS при 67% KILL по выборке. Здесь фиксируется до прогона:

- **n = 30 seed**, seeds `range(30)`
- **Статистика решения: медиана** `advantage_score`. Не среднее (устойчивость к
  выбросам), не одиночный seed, не «лучший из».
- Сообщаются также IQR и разбивка вердиктов — но решение принимается по медиане.

## Вторичное предсказание (диагностическое, не влияет на вердикт)

Из ограничения инструмента следует проверяемое следствие:

> Если кривизна работает как правило, её преимущество обязано **расти** по ходу
> прогона: `advantage(вторая половина шагов) < advantage(первая половина)`.

Если преимущество не растёт — правило не использует ту информацию, которая у него
единственная есть, и любой положительный итог требует другого объяснения.

## Гейты (наследуются из v2, без изменений)

G1 `C_initial > 0` · G2 доля `|dLk| = 1` ≥ 0.5 (теперь 1.00 по построению, A-003) ·
G3 `C_final(oracle) < C_initial` · G4 `accepted(curvature) ≥ 0.1 × accepted(random)`.

Любой непройденный гейт → `BLOCKED-INFRASTRUCTURE`, не KILL (FL Step 2a).
