# Claim R1 — параметры зафиксированы, и проверяется закон, а не точка

## Что было не так с первым прогоном

`decision.md` дал INCONCLUSIVE по двум причинам, обе — дефекты пре-регистрации:

| Дефект | Следствие |
|---|---|
| `capacity_ratio` не зафиксирован | величина эффекта гуляла от 1.008 (ρ=0.5) до 313 (ρ=1.2) |
| граница шума сенсора не задана | эффект обращался в свою противоположность при шуме > 0.5 |

R1 закрывает оба. Но простое повторение с пином было бы бедным экспериментом, поэтому
первичным вопросом делается то, чего я **не знаю**.

## Первичный вопрос: закон безубыточности — это закон?

В первом прогоне при гетерогенности популяции CV = 0.5 точка безразличия между адресным
и равномерным управлением пришлась на шум сенсора ≈ 0.5. Совпадение с CV популяции
выглядит как закон, но **наблюдалось ровно один раз, при одном CV**.

> **Замороженное утверждение:** точка безубыточности по шуму сенсора совпадает с
> гетерогенностью популяции в пределах фактора 2:
> `|log₂(noise_breakeven / CV_pop)| ≤ 1` для CV_pop ∈ {0.25, 0.5, 1.0, 2.0}

| Порог | Значение |
|---|---|
| SUCCESS | соотношение выполняется для **≥ 3 из 4** значений CV |
| KILL | нарушается для **≥ 2 из 4**, либо точка безубыточности не определена |
| Серая зона | ровно 2 из 4 → INCONCLUSIVE, **стоп и доклад** |

**Почему это может провалиться:** безубыточность могла бы масштабироваться как `√CV`,
или быть константой, или вовсе не существовать при малых CV. Я видел одну точку и
экстраполирую — ровно та ситуация, где экстраполяция обычно и ломается.

## Вторичный вопрос: держится ли эффект в КОНСЕРВАТИВНОЙ точке

Второй прогон с параметрами, зафиксированными **до** запуска и выбранными **не в свою
пользу**:

```
capacity_ratio = 0.80     # нижний край области, где эффект существует, НЕ 1.0
sensor_noise   = 0.10     # ненулевой, реалистичный сенсор
CV_pop         = 0.50     # как в первом прогоне
порог: advantage_excess >= 1.20   (унаследован из A-005, не менялся)
```

**Почему именно эти значения.** ρ = 1.0 из первого прогона — точка, где пропорциональное
распределение даёт каждой органелле ровно её нагрузку, то есть идеальный случай.
ρ = 0.8 при нулевом шуме давал 1.334 — запас над порогом всего 11%. Добавление шума 0.1
может его съесть. **Исход заранее неочевиден, и выбран он именно поэтому.**

Выбирать точку после просмотра ландшафта честно только так: брать не лучшую, а трудную.
