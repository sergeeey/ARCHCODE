CONTRIBUTION SUMMARY
This work presents ARCHCODE, a computational framework designed to test six competing hypotheses about whether 3D chromatin structure predicts variant pathogenicity. We developed contact-matrix simulations based on loop-extrusion biophysics, tested them on 25,850 ClinVar variants across nine genomic loci, and systematically killed all chromatin-based hypotheses using pre-registered criteria.

KEY FINDINGS
1. Variant functional category alone (promoter vs missense vs splice site) predicts pathogenicity with AUC = 0.791
2. Adding structural features (ARCHCODE LSSIM) yields ΔAUC = 0.001 — no predictive improvement
3. All six 3D-based hypotheses failed independently; only the "category artifact" hypothesis survived
4. ARCHCODE simulations correctly identified mechanism-specific patterns, but these are category-dependent, not category-independent

SIGNIFICANCE & NOVELTY
The null result is methodologically significant. We demonstrate:
- Category-matched controls to eliminate confounding in genomic studies
- Pre-registered hypothesis testing with git-timestamped kill criteria
- Falsification-first research design that prioritizes honest reporting over publication bias

This framework prevents wasted development on approaches already exhausted by prior hidden-fail files. Computational biologists will save months by learning which chromatin-based predictors we tested and why they failed.
