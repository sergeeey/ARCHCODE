# Урок 2 — Высокий AUC это красный флаг

## Что произошло

AUC=0.975 мы воспринимали как доказательство. На деле это был признак утечки через конфаундер — категория варианта (missense/splice vs intronic) коррелировала с меткой.

## Правило

AUC больше 0.95 на реальных биологических данных — немедленно ищи утечку. Настоящие биомедицинские задачи дают AUC 0.70-0.85. Если модель "идеальна", она скорее всего читает метку через чёрный ход.

## Как применять

Для любой метрики, которая выглядит "слишком хорошо":

1. Тестируй within-category
2. Проверяй корреляцию фичей с лейблами через простой confound
3. Убирай по одной фиче и смотри, какая "делает всю работу"

## Красные зоны AUC

- 0.60-0.75 — типичный результат для сложных биомедицинских задач
- 0.75-0.85 — хороший результат, скорее всего реальный
- 0.85-0.95 — проверь на утечку, но может быть реальным
- 0.95+ — почти наверняка confound или data leakage
