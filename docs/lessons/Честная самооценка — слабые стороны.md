# Честная самооценка — слабые стороны (апрель 2026)

> На основе анализа 27 проектов на 3 дисках. Не шаблонные "я перфекционист", а реальные паттерны из данных.

## 1. Finishing gap
27 проектов, 1 PyPI релиз. 6 frozen at 80%. Последние 20% (verdict, paper, release) систематически не делаются.

## 2. Breadth без depth
7 доменов. В каждом — рабочий прототип. Ни в одном — признанный эксперт или цитируемая публикация.

## 3. Одиночка без сети
0 коллабораторов. 0 внешних contributors. bioRxiv rejected (no affiliation). Нет научной сети, mentors, co-authors.

## 4. Confirmation bias + AI echo chamber
ARCHCODE: 6 месяцев Claude подтверждал гипотезу. Skeptic Engine позвали слишком поздно. Склонность строить evidence ЗА, а не ПРОТИВ.

## 5. Инфраструктурный перфекционизм
5 infra проектов, 2000+ тестов. Обслуживают проекты с 0 пользователей. Двигатель идеален, машина не едет.

## 6. Documentation sprawl
Reflexio 54 md, VeriFind 50+ docs. Пишешь документацию когда нужно код. Пишешь код когда нужно отправлять.

## 7. Не умеешь убивать
6 frozen проектов без явного KILLED. "Подожду" — не статус, а отказ от решения.

## 8. Publication как afterthought
Публикация планируется после работы, не параллельно. Результат: работа есть, площадки нет.

## 9. Масштабирование до валидации
18 локусов до baseline. 9 Docker контейнеров до golden set 25%. Фичи до core.

## 10. Нет revenue и нет плана
27 проектов, 0 дохода. Нигде нет "когда начнём зарабатывать". Проекты из savings.

---

## Что с этим делать

Каждая слабость — обратная сторона силы:

| Слабость | Обратная сила | Решение |
|----------|--------------|---------|
| Finishing gap | Быстрый старт | KILL_CRITERIA.md + deadline |
| Breadth без depth | Полимат | Выбрать 3, заморозить 23 |
| Одиночка | Автономность | 1 коллаборация в месяц |
| Confirmation bias | Энтузиазм | Red team каждый milestone |
| Infra перфекционизм | Качество кода | Infra = means, не end |
| Doc sprawl | Документирование | 5 docs max per project |
| Не убиваешь | Оптимизм | 30-мин verdict для frozen |
| Publication afterthought | Делаешь работу | Publication = workstream |
| Scale до validation | Амбиция | Gate review перед расширением |
| Нет revenue | Наука > деньги | 1 monetization experiment |
