# TERAG Desktop 2026

**Одно предложение:** Autonomous AI analyst platform — самостоятельно исследует данные, накапливает knowledge graph, работает 24/7 без участия человека.
**Статус:** Active (Integration Phase, v1.0.0)
**Стек:** Python 3.11, FastAPI, Neo4j, ChromaDB, Redis, Ollama (deepseek-r1:8b), React + Three.js, Prometheus/Grafana
