# Урок 17 — Evidence markers снижают галлюцинации

## Что произошло правильно

Система маркеров VERIFIED / INFERRED / UNKNOWN / WEAK заставляла явно указывать уровень уверенности. Когда p=0.0001 для MPRA оказалось галлюцинацией — именно потому что оно не было помечено VERIFIED. Реальное значение (p=0.91) было найдено и записано как VERIFIED.

## Конкретные результаты

- Все 38 DOI в рукописи помечены VERIFIED (HTTP request)
- Ключевые числа (p=4e-6, d=2.1, 20 pearls) помечены VERIFIED с источником
- Фантомное p=0.0001 было из MEMORY — система правильно классифицирует MEMORY как ненадёжный источник

## Правило на будущее

Маркируй уровень уверенности в КАЖДОМ утверждении с числом. Дорого? Нет — это 1 слово. Дешевле, чем опровержение после публикации.

## Как применять

- VERIFIED — подтверждено инструментом (Read, Bash, тест)
- INFERRED — логический вывод из verified фактов
- MEMORY — из прошлого опыта (может быть неточным!)
- UNKNOWN — не проверено, требуется верификация
- Правило: MEMORY без перепроверки = максимум LOW confidence
- Числа без маркера = не существуют
