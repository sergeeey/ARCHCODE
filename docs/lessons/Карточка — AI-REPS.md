# AI-REPS (Лаборатория рассуждений)

**Одно предложение:** Hybrid LLM reasoning system с virtual board of agents (Financier, Counterfactual, Designer, Seller) на Ollama + cloud fallback.
**Статус:** Active
**Стек:** Python (FastAPI, LangGraph), Node.js (Vite), Ollama/Gemini/Groq/Together, PostgreSQL, Redis
**Где:** E:\AL PERS Лабаратория рассуждений
