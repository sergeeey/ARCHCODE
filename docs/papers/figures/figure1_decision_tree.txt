Decision Logic Examples:

1. High-confidence theater detection:
   synthetic marker (0.3) + F1=1.000 (0.5) + synergy (0.25) = 1.05 → 0.70 HIGH

2. Mitigated by external source:
   F1=1.000 (0.5) + external_source (-0.30) = 0.20 LOW

3. Unit test suppression:
   "all tests passed" (0.3) + def test_ context (-0.25) = 0.05 LOW

4. Validation context escalation:
   F1=1.000 (0.5) + "validation" keyword → MEDIUM escalated to HIGH
