# Уроки ARCHCODE — финальные (16 апреля 2026)

Полный список уроков после закрытия проекта. Разделены на ошибки и победы.

---

## Ошибки (что не повторять)

### 1. Baseline не проверен в первый день
Category-to-score mapping давал AUC=0.98 без физики. Проверка заняла бы 1 час. Вместо этого 4 месяца строили на ложном фундаменте.
**Правило:** любой ML/scoring проект начинается с тривиального baseline.

### 2. AUC больше 0.95 на биоданных = красный флаг
Не победа, а сигнал confound. В ClinVar pathogenic = coding, benign = non-coding. Любой инструмент, который видит категорию, получит высокий AUC.
**Правило:** AUC больше 0.95 требует within-category проверки прежде чем праздновать.

### 3. Масштабирование до фальсификации
18 локусов настроены до того, как один прошёл within-category тест. Каждый новый локус = ещё 2 дня работы на непроверенном фундаменте.
**Правило:** докажи на одном, потом масштабируй.

### 4. AI усиливает confirmation bias
Claude подтверждал гипотезу 6 месяцев без вызова. Phantom reference (Sabate 2025 не существует). MPRA p-value галлюцинация (0.0001 вместо 0.91). AlphaGenome mock без пометки SYNTHETIC (11756 строк).
**Правило:** AI-ассистент нуждается во внешнем skeptic. Один AI не должен и строить и проверять.

### 5. Effort не равно evidence
299 коммитов, 90 страниц рукописи, 140+ скриптов — не заменяют один matched-control тест. Количество работы не коррелирует с качеством доказательств.
**Правило:** один правильный тест стоит больше чем 100 неправильных.

### 6. Unmatched comparison выглядит убедительно
AlphaGenome p=4e-6 казался железным. Но: promoter vs intronic, 11/12 в одном кластере. Без matched-control любой p-value — потенциальный артефакт.
**Правило:** значимость без matching = ложная уверенность.

### 7. Pseudo-replication маскирует weak evidence
12 "независимых" наблюдений оказались 2-3 (73bp кластер). Effective n не равен nominal n.
**Правило:** проверяй независимость наблюдений до расчёта p-value.

### 8. Sensitivity map может повторять вход
H-14 показал rho=0.017 (кажется нетривиально). Но 80% бинов на floor. Фильтрация: rho=0.72-0.81. Модель воспроизводит свой input, не добавляет topology.
**Правило:** при любой корреляции проверяй floor compression и range restriction.

### 9. Публикации с устаревшими claims — долг
Research Square preprint содержит claims, убитые через 2 недели после подачи. Preprint online = публичное утверждение. Обновление — обязательство, не опция.
**Правило:** обновляй публикации при каждой фальсификации.

### 10. Sunk cost fallacy тянет проект
После каждого kill — искушение найти "ещё один угол". H-01, H-14, pearl matched-control — всё это попытки спасти мёртвый проект. Каждая стоила часы.
**Правило:** заранее определи kill criteria. Если 3 гипотезы подряд убиты — остановись.

## Победы (что повторять)

### 11. Self-falsification до рецензии
Нашли category confound сами. Это лучше чем Reviewer 2 найдёт и отклонит. Сэкономило репутацию.
**Правило:** свой skeptic engine дешевле чужого rejection.

### 12. Integrity Protocol (CLAUDE.md)
230 строк жёстких правил: no phantom references, no invisible synthetic, no fitted without code. Поймали 3 реальных нарушения.
**Правило:** правила целостности пишутся ДО работы, не после аудита.

### 13. 24 архитектурных решения задокументированы
Ни одно решение не пересматривалось дважды. Каждое имело обоснование, контекст, альтернативы.
**Правило:** ADR экономят время при возвращении к проекту.

### 14. Null results как данные
MPRA p=0.91 стал доказательством blind spot (не провалом метода). SCN5A null стал tissue-specificity control. Каждый "провал" = информация.
**Правило:** null result = результат. Документируй, не скрывай.

### 15. Scope fence работает
.scope-fence.md не давал уйти в SaaS, Docker, новые skills, конкурентов. Фокус держался на науке.
**Правило:** scope fence на каждый проект, проверять каждую сессию.

### 16. Validation suite как standalone продукт
30 тестов, 6 модулей, меньше 30 секунд. Из провала родился инструмент с самостоятельной ценностью.
**Правило:** infrastructure от провалившегося проекта может пережить сам проект.

### 17. Мост между проектами
Навыки из ARCHCODE (falsification, matched-control, baseline testing) перенесены в Nobel Premia Boiko. Провал в геномике стал фундаментом для fraud detection.
**Правило:** skills переносятся между доменами. Проект может быть мёртв, а навыки — живы.

### 18. Honest negative result = уважение
Endorsers и рецензенты уважают честность больше чем красивый AUC. Negative result paper публикуем.
**Правило:** честный провал ценнее красивого обмана.

### 19. Memory system обеспечивает непрерывность
activeContext.md + decisions.md + patterns.md = непрерывность через 50+ сессий. Без памяти каждая сессия начинается с нуля.
**Правило:** memory system на каждый проект с первого дня.

### 20. Matched-control = главный инструмент
Каждый раз когда применяли matched-control — claim умирал (Router p=0.996, within-category AUC=0.52). Это не баг — это фича. Matched-control = фильтр правды.
**Правило:** если claim не проходит matched-control — он не стоит публикации.

---

## Мета-урок

ARCHCODE научил одной вещи: **процесс проверки важнее результата проверки.** Validation suite, integrity protocol, matched-control methodology — всё это переживёт конкретный проект и будет работать в следующем.
